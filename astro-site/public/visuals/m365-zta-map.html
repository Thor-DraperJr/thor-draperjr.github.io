Coverage climb by ZTA pillar

Each bar shows the coverage score of one pillar (full = 1, partial = ½). Segments show how much each tier adds. The dotted segment is the part that only a product outside the suite closes.

Method: The layout follows the updated Microsoft Zero Trust architecture (with Agent and Workload identities, External endpoints, Access Controls, AI Resources, In-App Controls, and Posture Management). Each component is rated for E3, E5, and E7 with the same rules as the coverage matrix: 0 = none, ½ = partial, 1 = full. Ratings are a simplified, opinionated view for discussion, not a formal licensing statement. “Outside the suite” means that no Microsoft 365 E-suite includes the product: for example, Defender for Cloud and Azure API Management (Azure purchases) or Entra Workload ID Premium (a standalone Entra SKU that is not in Entra ID P2 or the Entra Suite).

Sources: Select a component. The details panel lists the Microsoft Learn pages for that component, and each underlined product or acronym opens its page.
